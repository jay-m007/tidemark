Everything happens in this tab. Your bookmarks are never uploaded.

Tidy up your bookmarks

Drop in the file your browser exports. Tidemark finds the same page saved twice, strips tracking junk from links, suggests tags and gives you a clean file to import back.

Choose your bookmarks file

or drop it here. It is an .html file.

How do I get the file?
Chrome, Edge, Brave
Open the bookmark manager (Ctrl+Shift+O), click the three dots, choose Export bookmarks.
Firefox
Press Ctrl+Shift+O, then Import and Backup, then Export Bookmarks to HTML.
Safari
File menu, Export, then Bookmarks.

Your bookmarks

Takes out utm_ codes, fbclid, gclid and similar parts that only say where you clicked from. The page stays the same.

Same page, saved more than once

The copy marked keep is the one with tags, a note or a folder, otherwise the oldest. Untick a copy to keep it.

Possibly the same

Same site and same title, but different addresses. These are never removed unless you tick them.

    Suggested tags

    Based on the site, the folder and the title. Click a tag to turn it off. Nothing is applied until you export.

        Putting it back in your browser

        Your browser merges an imported file with what it already has, so the old copies would stay. For a clean result, import into a fresh profile, or delete the old bookmarks first and then import this file.
